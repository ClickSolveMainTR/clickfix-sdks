# ClickFix SDKs

Official client libraries for the [ClickFix](https://getclickfix.com) customer support platform.

| Package | Registry | Path |
|---|---|---|
| `@clickfix/node` | npm | `node/` |
| `@clickfix/react-widget` | npm | `react-widget/` |
| `@clickfix/visitor-core` | npm | `visitor-core/` |
| `clickfix_webview` | pub.dev | `flutter/clickfix_webview/` |
| `github.com/ClickSolveMainTR/clickfix-sdks/go` | Go module | `go/` |

This repository is a read-only mirror published by the ClickFix release pipeline: every
release pushes the `sdks/` tree of the main codebase here and tags it. Issues and pull
requests are welcome; fixes land in the main codebase and appear here with the next release.

Documentation: the integration guide at https://getclickfix.com/docs/integration-guide.

## Versioning

Each package has its own version and `CHANGELOG.md`. Tags follow `<package>/v<version>`
(for example `node/v0.1.0`, `go/v0.1.0`, `flutter/v0.1.0`).
